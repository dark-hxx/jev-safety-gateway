# 目标

优化管理控制台「最近请求」区域的可用性。当前只有「判定状态」一个筛选项，日志列表一次性平铺展示（最多 200 行），既没有分页也没有高度限制，长列表把整个页面撑得过长、难以浏览。目标是提供更丰富的筛选（判定状态、模型、关键词、时间范围）、服务端分页浏览，并把列表约束在有限高度内滚动。

# 范围

- 前端 `web/index.html`、`web/app.js`、`web/style.css` 中「最近请求」卡片的筛选、分页与布局。
- 后端 `internal/admin/handler.go` 的 `/api/logs`：新增 `offset`、`model`、`q`（关键词）、`since`（起始时间，unix 毫秒）查询参数，返回 `{items, total}`。
- 后端 `internal/config/store.go`：新增按条件分页查询并返回总数的能力（在 `RecentLogs` 基础上扩展或新增查询方法）。
- 控制台整体字体（`web/style.css` 的字体栈），从当前观感改为更美观的系统字体栈。
- Web 资源经 `//go:embed` 打包，任何改动都需要重新 `go build`。

# 非目标

- 不改动请求过滤/代理主链路（`internal/proxy`）。
- 不改动统计卡片（`stats`）、配置表单、密钥管理。
- 不引入前端框架或构建工具，保持零依赖原生 SPA。
- 不改动日志的写入结构（`AddLog` 字段与 `logs` 表结构不变）。
- 不新增「来源 IP」独立筛选项（关键词搜索已覆盖对 IP 的模糊查找）。

# 验收示例

- 「最近请求」卡片提供判定状态、模型、关键词、时间范围四类筛选控件；改变任一控件后，列表以当前全部筛选条件（四者为「与」关系）重新向 `/api/logs` 查询并重置到第 1 页。
- 列表按服务端分页展示，每页固定 50 条；卡片显示「第 X / 共 Y 页」与总条数，并提供「上一页」「下一页」按钮翻页。
- 位于第 1 页时「上一页」按钮禁用；位于最后一页时「下一页」按钮禁用。
- `/api/logs` 接受 `limit`、`offset`、`decision`、`model`、`q`、`since` 参数并返回 `{items, total}` 结构；用户可通过逐页翻阅浏览数据库中符合条件的全部历史日志，不再受原单次 200 行窗口限制。
- 当前筛选条件无匹配记录时，列表显示「暂无记录」，「上一页」「下一页」均禁用，页码显示为第 1 / 共 1 页。
- 日志列表容器设有最大高度，当前页记录超出时容器内部纵向滚动、表头吸顶，页面整体不再被长列表撑开。
- 现有能力不回退：判定状态筛选、时间列本地化显示、送检内容预览的 HTML 转义（防 XSS）保持有效。
- 控制台正文与等宽字体改用优化后的系统字体栈（不引入 CDN 或内嵌字体文件），离线环境仍可用且保留兜底字体。
- `go build -o gateway ./cmd/gateway` 与 `go vet ./...` 均通过。

# 约束与不变量

- 保持纯原生前端（无框架、无打包器），沿用现有 `api()` 助手与暗色主题变量。
- 保持对 XSS 的转义（`escapeHtml`）不回退。
- 后端分页查询的 `limit` 上限与既有语义一致（limit ≤ 1000），`offset` 非负；参数缺省时行为安全（默认按时间倒序返回首页）。
- 用户可见文案保持中文，与现有 UI 一致。
- 关键词搜索采用 SQL `LIKE` 子串匹配，参数化查询，避免注入。

# 决策

- 工作区隔离方式：`current`（当前目录、当前分支 main），无并行需求。
- Q1（筛选维度）：新增「模型」「关键词」「时间范围」三类筛选，不新增独立「来源 IP」筛选（关键词已覆盖 IP 模糊匹配）。
- Q2（分页架构）：采用服务端分页 + 服务端筛选，`/api/logs` 返回 `{items, total}`，可翻阅全部历史。
- 每页固定 50 条（不提供页大小切换，保持简洁）。
- 关键词 `q` 对 path、model、ip、reason、snippet 做 `LIKE` 子串匹配；模型 `model` 对 model 列做 `LIKE` 子串匹配。
- 时间范围用预设下拉（全部 / 最近 1h / 6h / 24h / 7天），前端换算为 `since` 毫秒时间戳传给后端。
- 列表容器最大高度约束为可视高度内滚动，表头吸顶。
- Q3（字体）：优化系统字体栈（零依赖、离线可用），不引入 CDN 或内嵌字体文件。正文优先 Inter / 思源黑体 / 苹方 / 微软雅黑等优质系统字体并保留兜底；等宽（`.mono`）列用 JetBrains Mono / SF Mono / Cascadia 等系统等宽字体栈。
