# 目标

依据 `docs/prototype/` 中的原型界面重构管理控制台：从当前「单文件 `index.html` + 单文件 `app.js` + 单文件 `style.css`」升级为可长期演进的 Vue 工程，落地**登录与初始配置**、**安全监控驾驶舱**、**网关与安全策略配置**、**转发审计记录**四个界面；同时逐项核对原型所需的**数据与操作能力**，对当前后端无法支撑的部分同步给出后端方案设计（接口、数据模型、库表、采集点），并在界面中以明确的降级形态呈现，留待后续 change 补齐。

登录与初始配置界面（`jev_3`）在本轮需求修订中由非目标移入交付范围：用户明确要求该界面按原型还原，同时对与后端事实冲突的元素按「分类处理」口径降级（见「决策」Q3、Q6–Q10）。

来源材料：`docs/prototype/jev_4/code.html`（驾驶舱）、`docs/prototype/jev_1/code.html`（网关配置）、`docs/prototype/jev_2/code.html`（转发审计记录）、`docs/prototype/jev_3/code.html`（登录与初始配置）、`docs/prototype/cupertino_safety_gateway/DESIGN.md`（设计系统令牌）。

# 范围

**前端工程化**

- 引入 Vue 3 + Vite + TypeScript + Tailwind 工程，源码入库；构建产物提交至仓库并由 `//go:embed` 打包，`go build ./cmd/gateway` 与单阶段 Dockerfile 保持不变，构建与运行阶段都不需要 Node。
- 控制台壳与导航：左侧导航（运行概览 / 网关安全配置 / 转发审计记录）、顶部状态条、暗色 Cupertino 主题令牌（以 `DESIGN.md` 为基线）。
- 导航与路由：左侧导航由 vue-router 驱动，每个界面是独立的路由页面（独立视图组件 + 独立模块目录），视图切换走路由而非壳层内的条件渲染；新增界面只需注册一条路由与一个模块，不改动壳层。路由模式见决策 Q13。
- 离线约束下的资源策略：原型使用的 Tailwind CDN、Google Fonts、Material Symbols 全部替换为本地等价物。

**四个界面按原型还原**

- 登录与初始配置（`jev_3`）：居中 440px 玻璃认证卡与背景环境光晕；App 图标与渐变光环；居中标题与副标题；`验证登录` / `初始配置` 双模式分段控件（当前模式由 `GET /api/setup-status` 决定，另一项呈禁用态，避免提交到与后端状态不符的接口）；口令输入行含左置图标、右置可见性切换与右侧元信息；带箭头的主按钮；守护进程状态胶囊；安全标语；页脚；提交结果以浮动提示呈现。
- 驾驶舱（`jev_4`）：KPI 卡、时间范围分段控件、流量与安全威胁态势趋势图（接后端分桶序列）、风险分值分布图（取代原型的「威胁类型四分类占比」，接后端分值直方图）、集群状态区（降级）、快捷跳转。
- 网关与安全策略配置（`jev_1`）：上游服务与 JEV 检定路由、安全防护与自动拉黑策略、调用密钥池分发三个分组的表单控件。
- 转发审计记录（`jev_2`）：统计条、判定状态分段、四类筛选、活跃条件 chips、高密度表格、分页、详情抽屉。

**数据接入**

- 能用现有后端接口的一律接现有接口：`/api/state`、`/api/settings`、`/api/keys`、`/api/logs`、`/api/stats`。
- 驾驶舱的两张统计图需要按时间分桶与按分值分桶的真实聚合，按其口径**由后端统计、前端展示**（决策 Q11、Q12）：扩展 `GET /api/stats` 的响应，新增按时间分桶的计数序列与按分值分桶的直方图。这是本次唯一允许的后端改动，边界见非目标。
- 后端撑不住的（见后端缺口清单）以明确降级态呈现，不显示伪造数值。

**后端缺口清单与方案设计（文档）**

- 逐项列出现有后端不支持的界面元素，每项给出接口路径与方法、请求/响应字段、库表或数据模型变更、采集点位置、降级策略。
- 涉及代理主链路（`internal/proxy`）的埋点单独标注侵入范围与兼容性影响，供后续 change 决策。

# 非目标

- **本次不补齐后端缺口**（本轮按 Q11 收窄）：不新增 `/api/*` 路径、不改 `logs` 表结构（表与列均不变，`idx_logs_ts` 现有索引已覆盖按时间范围的聚合）、不改 `internal/proxy` 的埋点、不改变过滤主链路的判定语义与响应头与 SSE 透传。允许的唯一后端改动是在 `internal/config` 增加**只读聚合查询**并扩展 `GET /api/stats` 的响应字段（决策 Q11、Q12）；其余缺口仍只出设计 + 界面降级，后续 change 落地。
- **不实现界面语言切换**：原型顶栏的 `中文` / `EN` 分段控件与完整英文案表只作为需求来源记录，不进入实现，界面文案保持中文。若后续确需全站中英切换，需另立 change 并引入 i18n 层。
- **不新增「保持受信任凭据」能力**：原型「保持本工作站受信任凭据 (24h)」勾选项不呈现；`/api/login` 不新增 remember-me 参数，管理口会话时长沿用现有 12 小时滑动过期，不因本次重构改变。
- **不为无数据来源的装饰性元素发明数据**：多集群节点与地理位置拓扑、WORM 合规归档与审计校验码、集群 SLA/Overhead、Token 估算等，统一降级呈现或明确不纳入。驾驶舱的两张统计图已按决策 Q11、Q12 改为由后端真实聚合后绘制，不再属于本条。
- **不改变过滤主链路行为**：放行/拦截/跳过/错误的判定语义、`X-JEV-Gateway` / `X-JEV-Score` 响应头、SSE 流式透传均保持现状。
- **不引入运行期外部依赖**：不新增独立进程或外部服务（Redis、外部 GeoIP 服务、外部指标系统等）。
- **不重新设计视觉语言**：以原型与 `DESIGN.md` 为准。

# 验收示例

- 控制台由 Vue 3 + Vite + TypeScript + Tailwind 工程构建；仓库同时包含源码与构建产物，`go build -o gateway ./cmd/gateway` 直接产出含完整界面的二进制，构建与运行阶段都不需要 Node。
- 界面不依赖任何公网 CDN：原型引用的 Tailwind CDN、Google Fonts、Material Symbols 均以本地等价物替代，离线环境加载不发外部请求。
- 暗色 Cupertino 主题令牌（调色板、字体族、8pt 间距、发丝边框、圆角与材质）以 `DESIGN.md` 为基线落地为 Tailwind 主题与基础样式。
- 三个界面可按原型导航到达且结构完整：驾驶舱、网关与安全策略配置、转发审计记录。
- 左侧导航由路由驱动：三个界面各为独立路由页面，可通过 URL 直接打开、并在浏览器前进/后退中正确切换；界面按模块目录组织，新增界面只需注册路由与模块、不改动壳层。
- 网关配置界面覆盖原型的三个分组表单，并可直接读写现有接口：设置项经 `/api/settings` 读取与保存（改值保存后刷新仍生效），密钥池经 `/api/keys` 及其子路径完成新增、启用/停用与删除。

# 约束与不变量

- **部署形态不变**：单个 Go 二进制，Web 资源经 `//go:embed` 打包，纯 Go 无 CGO；`go build ./cmd/gateway` 必须仍然产出可直接运行的完整二进制。
- **离线可用**：控制台不得依赖公网 CDN。原型使用的 Tailwind CDN、Google Fonts、Material Symbols 外链只能作为设计参考，不能作为运行期依赖；字体沿用既有约定（系统字体栈，不引 CDN、不内嵌字体文件）。
- **代理主链路不变**：`internal/proxy` 的判定语义、响应头、流式透传不因本次重构改变。
- **用户可见文案保持中文**（原型中的英文副标题、`Dashboard` 等双语标签沿用原型）。
- **现有能力不回退**：日志多条件筛选与服务端分页（`/api/logs` 的 `limit`/`offset`/`decision`/`model`/`q`/`since` 与 `{items,total}`）、送检内容预览的 HTML 转义、离线系统字体栈。
- **管理口安全边界不变**：管理口默认仅监听 `127.0.0.1`，`/api/*` 除 `login`/`setup`/`setup-status` 外一律要求 bearer token。
- **不伪造数据**：任何界面元素都不得展示无后端来源的数值；无来源者一律降级。
- **不新增运行期外部服务**：所有数据缺口只能用「现有 SQLite + Go 进程内」手段解决，或明确标注为降级/不纳入。

# 决策

- **工作区隔离方式**：`current`（当前目录、`main` 分支、无并行需求）。
- **能力关联**：本 change 关联已有 capability `admin-console`（`docs/comet/specs/admin-console/spec.md`），其目标规格由本 change 改写为覆盖整个管理控制台（壳与导航 + 三界面）。
- **Q1 交付范围**：本 change 落地前端重构（Vue 工程 + **四个界面** UI + 路由化改造），后端缺口只出设计并在 UI 中降级呈现；后端补齐作为后续独立 change。用户先用「根据原型界面对产品前端架构进行方案设计……不满足的话需要同步列出后端的方案设计」，后续明确「方案设计完成了，现在开始实现」。本轮再次修订：登录界面移入交付范围（Q3），导航改为路由驱动的独立页面，并放开一处后端改动以支撑驾驶舱两张图表（Q11、Q12）。
- **Q2 前端技术栈**：采用 Vue 3 + Vite + TypeScript + Tailwind，本地构建。产物提交入库并经 `//go:embed` 打包，`go build` 与单阶段 Dockerfile 保持不变；Node 仅在开发期需要。
- **Q3 界面范围**：驾驶舱、网关配置、转发审计记录三个业务界面；**登录与初始配置界面（`jev_3`）在本轮需求修订中移入范围**，按原型还原结构与交互。原决定「保持现状、仅纳入覆盖表读取与差异记录」由用户本轮明确要求取代。
- **Q6 界面语言**：不实现语言切换。原型顶栏的 `中文` / `EN` 分段控件与完整英文案表只作为需求来源记录，不进入实现，界面文案保持中文。理由：「约束与不变量」已约定用户可见文案保持中文，而全站 i18n 会牵出四个界面全部文案，超出本次范围。
- **Q7 受信任凭据勾选项**：不呈现原型「保持本工作站受信任凭据 (24h)」。理由：后端为 bcrypt 口令哈希 + 12 小时滑动会话（`internal/admin/handler.go` 中 `newSessions(12 * time.Hour)`），`/api/login` 无 remember-me 参数；按原型呈现 24h 属于展示无来源数值。已核实并决定不改会话时长。
- **Q8 装饰性与无来源元素口径（分类处理）**：静态标语类保留原文（`ZERO-TRUST TLS`、`PII SHIELD ACTIVE`）；含数值、地址或版本的降级为可识别的「未接入」标注且不显示伪造数值——版本徽标（无 `/api/version`，缺口 G23）、延迟徽标 `LATENCY <1.8ms`（缺口 G21）、守护进程地址胶囊（原型的 `127.0.0.1:8080` 是代理监听口，控制台实际在 8081，且从管理口跨源取不到代理状态）。与另外三个界面 A9 的口径一致。
- **Q9 口令哈希元信息**：输入行右侧元信息标注为 bcrypt，不沿用原型的 `SHA-256 授权`（英文案表更写作 `Argon2id Enforced`）。理由：`internal/admin/auth.go` 实际使用 `bcrypt.GenerateFromPassword` / `CompareHashAndPassword`，原型文案与实现不符。
- **Q10 登录页图标素材**：原型卡片图标的 `src` 指向 `lh3.googleusercontent.com`，与「离线可用 / 不引入运行期外部依赖」冲突，改用仓库内本地素材 `docs/prototype/jev_gateway_ios_app_icon/code.html` 的内联 SVG（viewBox `0 0 120 120`）。
- **Q11 驾驶舱趋势图的数据来源**：**由后端统计、前端展示**（用户本轮反馈明确）。实现为扩展 `GET /api/stats`：在既有 `hours` 区间总量字段之外，新增 `bucket_seconds` 与 `series`——按键值对逐桶给出 `{ts, total, allowed, blocked}`，覆盖 `[now-hours, now]` 的每一个桶（空桶补 0，保证曲线连续）。分桶粒度由 `hours` 确定性推导并回传，前端只负责渲染，不自行分桶。理由：`logs.ts` 已有 `idx_logs_ts` 索引，按区间聚合是索引范围扫描；前端分页拉取在 7 天窗口下需要多次请求且首屏更慢。这是本次唯一放开的后端改动，边界见非目标。
- **Q12 驾驶舱第二张图的口径**：原型「威胁类型四分类占比」在后端没有对应枚举字段（`logs` 只有判定结果与 `reason` 自由文本），按用户选择改为**风险分值分布**——同样由后端聚合，在 `/api/stats` 响应中新增 `score_buckets`：对区间内 `score` 非空的记录按 0.2 步长分 5 档（`[0,0.2)` … `[0.8,1.0]`，末档含 1.0）计数，另单列 `unscored`（`score IS NULL`，即跳过或 JEV 未返回分值的记录），使分布不隐藏任何样本。**统计口径为区间内全部已送检记录，而非仅拦截记录**：拦截的判定条件是「分值低于（或高于）阈值」，只统计拦截记录会让分布退化到阈值一侧的单一档位，失去信息量。卡片副标题标注实际样本量。
- **Q13 路由模式**：**history 模式**（用户确认）。`vue-router` 采用 `createWebHistory`，URL 形如 `/dashboard`、`/settings`、`/audit`。现有 `internal/admin` 用 `http.FileServer` 直接服务嵌入的 `dist`，深链接会 404，因此需在该静态服务上增加 SPA 回退：未命中静态文件且非 `/api/` 前缀的 GET 请求回退到 `index.html`。改动仅限静态文件服务，不新增 `/api/*` 路径、不改 `logs` 表、不改 `internal/proxy`。同时 `nginx/gateway.conf` 若代理管理口需放行对应路径。
- **Q4 后端缺口处理**：只设计、不实施。涉及代理主链路的埋点建议单独成节标注侵入范围与兼容性影响，供后续 change 决策。
- **Q5 送检内容持久化**：本期不新增全量送检正文持久化（隐私优先，与现有 `snippet` 字段语义一致）。审计详情抽屉中「原始 JSON Payload」呈现为降级态；全量持久化列为可选增强并标注隐私影响。
