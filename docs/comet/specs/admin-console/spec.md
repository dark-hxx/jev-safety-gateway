# 管理控制台「最近请求」日志浏览

管理控制台（`web` SPA + `internal/admin`）为运营者提供网关配置、密钥管理与请求日志浏览。本规格描述归档后「最近请求」日志浏览的完整目标行为，包含筛选、服务端分页与列表布局。

## 日志查询 API

`GET /api/logs` 需要有效 bearer token（沿用 `auth` 中间件），返回符合条件的日志分页结果。

- 接受查询参数：
  - `limit`：单页条数，整数；取值范围与既有语义一致（超出 `[1,1000]` 或缺省时回退到默认 50）。
  - `offset`：跳过的记录数，非负整数；缺省或非法时按 0 处理。
  - `decision`：判定状态精确匹配，取值 `allow|block|skip|error`；空表示不限。
  - `model`：模型名子串匹配（SQL `LIKE`）；空表示不限。
  - `q`：关键词，对 `path`、`model`、`ip`、`reason`、`snippet` 做子串匹配（SQL `LIKE`）；空表示不限。
  - `since`：起始时间，unix 毫秒；仅返回 `ts >= since` 的记录；缺省或 ≤0 表示不限。
- 所有筛选条件之间为「与」关系，同时生效。
- 结果按 `id` 倒序（最新在前）。
- 响应体为对象：`{"items": LogEntry[], "total": number}`，其中 `total` 是在**不含 `limit`/`offset`** 前提下满足其余筛选条件的总记录数，`items` 是应用了 `limit`/`offset` 后的当前页记录。
- `LogEntry` 字段与结构保持不变（id/ts/method/path/kind/decision/score/model/latency_ms/ip/reason/snippet）。
- 所有参数使用参数化查询，不做字符串拼接，避免 SQL 注入。

Scenario: 分页与筛选组合查询
WHEN 客户端携带 `decision=block&q=1.2.3.4&limit=50&offset=50`
THEN 服务端返回第 2 页（跳过前 50 条）中 decision 为 block 且 path/model/ip/reason/snippet 命中 `1.2.3.4` 的记录，`total` 为满足该筛选条件的全部记录数。

Scenario: 缺省参数安全回退
WHEN 客户端不带任何参数请求 `/api/logs`
THEN 服务端返回按 id 倒序的首页（默认每页 50 条、offset 0）与 `total`，不报错。

## 筛选控件

「最近请求」卡片头部提供以下筛选控件，均为中文文案：

- 判定状态下拉：全部 / 放行 / 拦截 / 跳过 / 错误（沿用现有取值）。
- 模型输入框：按模型名子串筛选。
- 关键词输入框：按关键词子串筛选（覆盖路径、模型、来源 IP、原因、送检预览）。
- 时间范围下拉：全部 / 最近 1 小时 / 最近 6 小时 / 最近 24 小时 / 最近 7 天；前端换算为 `since` 毫秒时间戳。
- 刷新按钮：以当前筛选条件重新查询当前页。

Scenario: 改变筛选回到首页
WHEN 用户修改任一筛选控件的值
THEN 列表以当前全部筛选条件重新向 `/api/logs` 查询，并重置到第 1 页。

## 服务端分页浏览

- 每页固定 50 条。
- 卡片提供「上一页」「下一页」按钮，以及「第 X / 共 Y 页」与总条数指示（Y 由 `total` 与页大小计算）。
- 位于首页时「上一页」禁用；位于末页（或结果为空）时「下一页」禁用。
- 翻页时携带正确的 `offset` 与当前筛选条件向 `/api/logs` 查询。
- 通过翻页可浏览数据库中符合条件的全部历史日志，不受单次固定窗口限制。

Scenario: 边界翻页按钮状态
WHEN 结果共 3 页且当前处于第 1 页
THEN 「上一页」禁用、「下一页」可用；WHEN 翻到第 3 页 THEN 「下一页」禁用、「上一页」可用。

Scenario: 结果为空
WHEN 当前筛选条件无匹配记录
THEN 列表显示「暂无记录」，「上一页」「下一页」均禁用，页码显示为第 1 / 共 1 页或等价的空态。

## 列表布局

- 日志表格外层容器设有最大高度，行数超出时容器内部纵向滚动，页面整体不被撑开。
- 表头在容器内滚动时吸顶可见。
- 送检内容预览等字段保持 `escapeHtml` 转义，防止 XSS。
- 沿用现有暗色主题变量与表格样式，横向仍可在窄屏滚动。

Scenario: 高度受限内部滚动
WHEN 当前页记录较多超出容器最大高度
THEN 列表在容器内纵向滚动，表头吸顶，页面其他区域位置不被列表长度影响。

## 字体

控制台使用美观的系统字体栈，不依赖外部网络字体或内嵌字体文件，离线部署仍可用。

- 正文字体栈优先选择系统上可用的优质无衬线字体（如 Inter、系统 UI 字体、思源黑体 / Source Han Sans、苹方 / PingFang、微软雅黑 / Microsoft YaHei），并保留通用兜底（sans-serif）。
- 等宽内容（`.mono` 类，如时间、路径、密钥、IP）使用系统等宽字体栈（如 JetBrains Mono、SF Mono、Cascadia Code、Consolas、ui-monospace），并保留 monospace 兜底。
- 不通过 `<link>`/`@import` 引入 CDN 字体，也不 `go:embed` 字体文件；不新增网络请求。

Scenario: 离线可用的系统字体栈
WHEN 控制台在无外网的环境中加载
THEN 正文与等宽文本均使用本地系统字体栈渲染，不因缺少网络字体而发起外部请求或退化为默认衬线字体。
