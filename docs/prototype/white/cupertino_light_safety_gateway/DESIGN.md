## Brand & Style

The design system delivers an authoritative, high-integrity mission control environment tailored for AI safety governance, real-time payload sanitization, and compliance routing. Informed by Apple's Human Interface Guidelines (HIG) across macOS and iPadOS, it manifests as a clean, bright, and crystalline workspace that pairs operational precision with effortless clarity.

### Aesthetic Foundation
- **Luminosity & Clarity:** An uncompromising focus on light mode purity. The UI leverages layered neutral system backdrops (`#F2F2F7` and `#F5F5F7`), pristine white cards (`#FFFFFF`), and optical translucent blurs that let content breathing room prevail over visual clutter.
- **Micro-Precision Engineering:** Hairline dividers (`rgba(0, 0, 0, 0.08)`), continuous curvature squircles, and calibrated negative space convey institutional security without corporate sterility.
- **Purposeful Vibrancy:** Color operates strictly as informative telemetry. Vibrant Apple system accents—System Blue, Emerald, Amber, Red, and Indigo—provide instantaneous status comprehension across dense token logs, safety matrices, and traffic inspectors.

## Colors

The color palette is anchored in classic Apple Cupertino light aesthetics. System canvases rely on nuanced cool-gray values that contrast gently with pure white containers, ensuring layered depth without dark, heavy boundaries.

### Core Canvas & Typography Tokens
- **System Canvas (`#F2F2F7` / `#F5F5F7`):** The foundational substrate for application split-views, workspace backgrounds, and gutter zones.
- **Surface Card (`#FFFFFF`):** High-readability container background reserved for primary audit panels, log inspectors, and telemetry cards.
- **Text Primary (`#1D1D1F`):** Deep obsidian for core metrics, table rows, and headings, offering optimal contrast.
- **Text Secondary (`#86868B`):** Muted slate used for descriptive metadata, column captions, timestamps, and placeholder copy.
- **Hairline Border (`rgba(0, 0, 0, 0.08)`):** A micro-stroke defining card perimeters, table row dividers, and control outlines.

### Semantic Status Palette
- **System Blue (`#007AFF`):** Primary interactive elements, selected navigation nodes, filtered search chips, and active gateway rules.
- **Success Emerald (`#34C759`):** Sanitized prompt tokens, passed validation suites, active microservices, and 200 OK statuses.
- **Warning Amber (`#FF9500`):** Soft threshold violations, latency spikes, rate-limiting warnings, and suspicious intent markers.
- **Danger Coral / Red (`#FF3B30`):** Hard prompt injection blocks, model jailbreaks, PII leakage prevention, and critical service dropouts.
- **System Indigo (`#5856D6`):** Synthetic benchmarks, ML model attribution, and cryptographic signature verifications.

## Typography

The typographic system emphasizes crystal clarity, proportional hierarchy, and humanized geometric neutrality reminiscent of Apple's SF Pro.

- **Primary UI Typeface (`Plus Jakarta Sans`):** Powers all headers, navigation elements, body text, and interactive controls. Crisp counters, open apertures, and subtle vertical ascenders ensure effortless scanning across complex security dashboards.
- **Monospace Telemetry:** Where token payloads, vectors, SHA-256 signatures, and network trace lines appear, developers should apply a monospace system font (such as `JetBrains Mono` or `SF Mono`) at `11px` to `13px` with tight `1.3x` line height to ensure precise column alignment.
- **Tracking Discipline:** Headings utilize tight negative letter spacing (`-0.01em` to `-0.02em`) to mirror native macOS Sonoma display titles, whereas micro labels (`caption-2`) feature positive tracking (`0.02em`) to eliminate optical crowding at small scale.

## Layout & Spacing

Layout geometry follows an 8-point rhythmic system optimized for high-density desktop and tablet console viewports.

### Architectural Layout
- **Split-View Canvas:** 
  - **Sidebar:** Fixed `260px` sidebar adhering to macOS split-navigation mechanics, collapsing to a floating navigation pill or drawer on smaller breakpoints.
  - **Main Console Area:** Multi-column fluid workspace spanning 12 columns with standard `20px` (`1.25rem`) gutters.
  - **Contextual Inspector:** `360px` docked right-hand drawer dedicated to prompt payload breakdowns, AST token trees, and firewall scoring telemetry.
- **Breakpoints:**
  - **Desktop (>= 1200px):** Full 3-pane split view, `32px` (`2rem`) outer margin.
  - **Tablet (768px - 1199px):** Collapsible sidebar, persistent workspace with slide-over inspector, `24px` margin.
  - **Mobile (< 768px):** Single stacked view with modal sheets, `16px` (`1rem`) outer margin, and `12px` (`0.75rem`) gutters.

## Elevation & Depth

Visual hierarchy does not depend on heavy, dark shadows. Instead, it relies on Apple-style optical layering, translucent glass surfaces, and ultra-fine hairline outlines.

### Elevation Hierarchy
1. **Canvas Level (Elevation 0):** Pure `#F2F2F7` or `#F5F5F7`. The quiet foundation across which all workspace modules live.
2. **Standard Surface Cards (Elevation 1):** Solid `#FFFFFF` surfaces with a 1px perimeter border rendered in `rgba(0, 0, 0, 0.08)`. Subtle ambient grounding shadow: `0 1px 3px rgba(0, 0, 0, 0.04), 0 4px 12px rgba(0, 0, 0, 0.02)`.
3. **Floating Controls & Segmented Thumbs (Elevation 2):** Pure `#FFFFFF` sliding indicators or popover surfaces backed with `backdrop-filter: blur(20px)` and soft directional shadow: `0 3px 8px rgba(0, 0, 0, 0.08), 0 1px 2px rgba(0, 0, 0, 0.04)`.
4. **Modals & Flyout Sheets (Elevation 3):** Floated above the main UI with `0 20px 40px rgba(0, 0, 0, 0.12)`, encircled by `rgba(0, 0, 0, 0.08)` and dimmed via a light translucent scrim (`rgba(0, 0, 0, 0.2)`).

### Hairline Borders
Every elevated element—from pill badges to inspector cards—is bounded by a crisp 1px border. In light mode, this defines boundary clarity without competing with high-contrast text.

## Shapes

The design system incorporates Apple squircle geometry through calibrated border-radius scales:

- **Primary Cards & Modals:** Standard `16px` to `18px` radius (`rounded-xl`), creating soft yet structured containment for dense tables and graphs.
- **Nested Containers & Sub-Panels:** `12px` to `14px` radius (`rounded-lg`) to preserve optical concentricity inside parent cards.
- **Controls & Form Elements:** `8px` to `10px` radius (`rounded`) for input fields, action buttons, and segmented selection tracks.
- **Pill Elements & Indicators:** Full radius (`9999px`) for badges, status chips, toggle switches, and quick filters.

## Components

### Buttons
- **Primary:** Apple System Blue (`#007AFF`) solid fill, white text, weight `600`, height `36px` (desktop) / `44px` (touch). Subtle hover state darkening to `#0066D6`, with a fine internal border `rgba(255, 255, 255, 0.15)`.
- **Secondary (Tonal Gray):** Filled with `rgba(118, 118, 128, 0.12)`, text `#1D1D1F`, hover shifting to `rgba(118, 118, 128, 0.18)`.
- **Destructive:** System Red (`#FF3B30`) light tint fill (`rgba(255, 59, 48, 0.1)`) with `#FF3B30` text for non-terminal actions, transitioning to solid `#FF3B30` fill with white text for irreversible rule deletions.

### Cupertino Segmented Controls
- **Track:** Capsule-shaped container filled with `rgba(118, 118, 128, 0.12)`, `8px` radius, and `2px` internal inset padding.
- **Thumb:** Pure `#FFFFFF` rounded indicator casting a crisp `0 2px 4px rgba(0, 0, 0, 0.08)` shadow. Text switches from muted `#86868B` to `#1D1D1F` on selection.

### Status Chips & Pills
- Rendered at `22px` height with a full pill radius (`9999px`) and padding `2px 10px`.
- Composed of an 8–10% opacity semantic tint and a solid 6px dot indicator:
  - **Passed / Normal:** `#34C759` (Emerald)
  - **Heuristic Warning:** `#FF9500` (Amber)
  - **Blocked / Policy Violation:** `#FF3B30` (Coral)
  - **Sanitized / Cryptographic:** `#5856D6` (Indigo)

### Inset Grouped Lists & Forms
- Follows the iOS System Settings grouped visual standard.
- Rows feature white backgrounds with `16px` horizontal padding and an inset `1px` divider (`rgba(0, 0, 0, 0.06)`) starting at the title baseline.
- Interactive accessories include Cupertino chevron glyphs, metadata callouts (`#86868B`), or smooth green toggle switches (`#34C759`).

### Input Fields & Search Bars
- Standard height `36px`, rounded `10px`, background `rgba(118, 118, 128, 0.08)`, and border `rgba(0, 0, 0, 0.08)`.
- Focus state reveals a gentle `#007AFF` halo ring with `0 0 0 3px rgba(0, 122, 255, 0.25)` and a crisp `#007AFF` stroke.

### High-Density Audit Tables
- **Header:** Sticky light gray header (`#F5F5F7`), uppercase `caption-2` tracking, height `32px`.
- **Rows:** Crisp `40px` height on pure white cards, alternating hover tint `rgba(0, 122, 255, 0.04)`. Monospaced cells for IP addresses, latency timings, and payload tokens.
